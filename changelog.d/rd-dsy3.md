### Added

- A `choice_question` takes `answer_options_from`, a path under `context` such as `"context.branches"`, in place of `answer_options`: `Riddler.Screens.resolve/2`, `Riddler.Screens.resolve_screen/3` and `Riddler.Journey.present/3` read the question's options from the root's `"context"` at that path, a list of objects each carrying a key-shaped `"value"` and a string `"label"`, no value twice, and carry them as `answer_options`, each its value and its label as the host gave them and not rendered as a template. A path that reaches no such list resolves the question with no options and is reported in `missing_variables`, its `variable` the path as written; an empty list is no options and is not reported.
- `Riddler.Screens.validate_screen/3` and `/4` check a response to such a question against the options the root's `"context"` holds when they are called, so a value the context no longer offers is `response.not_an_option`.
- `Riddler.Screens.Document.validate/1` refuses a choice question carrying both `answer_options` and `answer_options_from` as `document.conflicting_options`, an `answer_options_from` that is not a dotted path of key-shaped segments under `context` as `document.invalid_context_path` with `field` `"answer_options_from"`, and any `default` on a choice question that reads its options from context as `document.invalid_default`. A choice question carrying neither is still `document.missing_field` on `answer_options`.
- `priv/schemas/presented-answer.schema.json` refuses `answer_options_from` on a presented choice question and describes its `answer_options` as either the document's options or the options read from context, possibly none.

### Changed

- An `answer_options_from` on a choice question, which 0.4.0 admitted and dropped, is now read. A question carrying it and no `answer_options`, which 0.4.0 refused as `document.missing_field`, is now admitted and takes its options from context. A question carrying both, which 0.4.0 resolved from its `answer_options`, is now refused as `document.conflicting_options`: remove one of the two. A question whose `answer_options_from` is not a path under `context`, or that carries one and a `default`, is now refused: correct the path, or remove the default.
